# ScreenLasso

Prepare and convert images from a conversation, with the ScreenLasso app on your Mac.

## What it does

Ask for an image for Instagram, Stories, Reels or TikTok, Facebook, X, LinkedIn, Pinterest, a YouTube thumbnail or a link preview, and ScreenLasso crops it to the platform's shape, resizes it to the platform's exact size and saves it as an sRGB JPEG, so the platform doesn't rescale it before its own compression. It also makes WebP sizes for websites and converts images to WebP, AVIF, JPEG, PNG or HEIC, with your own ScreenLasso presets too.

## Set it up

1. Install ScreenLasso from the Mac App Store and open it.
2. In ScreenLasso › Settings › AI Agents, turn on **Let AI agents use ScreenLasso**.
3. Install this plugin and paste the key shown in that settings tab when you're asked for it.

## Use it

"Prepare ~/Pictures/beach.jpg for an Instagram post", "Make this screenshot a 1600 px WebP", or "Turn the images in ~/Pictures/Trip into Pinterest pins."

## Data

The plugin connects only to ScreenLasso on your own Mac, at 127.0.0.1. Images, file names and results stay on your Mac; nothing is sent to the plugin's author or any other service. ScreenLasso removes location and camera details from the files it saves.
